# APS Engine · 验证声明（结论可靠性依据）

> 本声明是插件结论可靠性的唯一依据。**插件未使用、未上传任何客户数据。**
> 所有训练/验证均在公开数据集与合成语料上进行；客户场景（参考试点）仅在本地运行，数据不出厂。

## 一、零客户数据承诺
- 本仓库不包含任何企业/客户数据（商品主数据、订单、产能、行业配置均不入库）
- 客户适配（商品映射、行业配置）仅存在于本地 `adapters/sku_map.json`、`config/industry_food.json`（已 gitignore）
- 仓库示例数据均为公开/合成来源（见下）

## 二、已用于训练与验证的数据集（结论可靠性的证据链）

| 数据集 | 来源 | 用途 | 结果 |

## 三、结论可靠性的机制
1. **可复现**：seed 固定、输入快照、引擎/数据/配置三版本绑定
2. **可核查**：5-Sheet 公式联动 Excel（改数联动、汇总勾稽）
3. **可检验**：假设-结论绑定（assumptions.json + 敏感度），校准状态可追溯
4. **可复现评测**：eval_suite.py 一键跑公开数据集

## 四、边界声明
- 插件不训练于任何企业数据；每个企业接入走 SOP：数据映射审计→假设声明→敏感度→用户确认冻结
- 预测/概率层结论依赖企业提供的历史数据长度（<3 个月时区间不可靠，已标注）
